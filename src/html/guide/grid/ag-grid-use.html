AG-Grid 사용 가이드

공통 모듈 ag-grid.common.js / ag-grid.utils.js 기반 그리드 작성 방법

1. 스크립트 로드 순서
그리드를 사용하는 페이지 하단 </body> 직전에 아래 순서대로 포함해야 합니다.
<script src="@@webRoot/js/grid/ag-grid.common.js"></script>
<script src="@@webRoot/js/grid/ag-grid.utils.js"></script>
<!-- 페이지별 그리드 초기화 스크립트 -->
<script src="@@webRoot/js/페이지명.js"></script>
2. GridCommon.init — 그리드 초기화
그리드를 생성하고 AG Grid API 인스턴스를 반환합니다.
baseOptions가 기본으로 적용되며 두 번째 인자로 커스텀 옵션을 병합할 수 있습니다.
기본 사용법
const myGridApi = GridCommon.init(document.querySelector('#myGrid'), {
  columnDefs: columnDefs,
  rowData: rowData,
});
baseOptions 기본값
옵션기본값설명
localeTextAG_GRID_LOCALE_KR한국어 로케일 (라이브러리 포함)
getRowIdString(data.id)행 고유키. 행 삭제·갱신에 필수. 데이터에 id 필드가 있어야 함
sortabletrue모든 컬럼 정렬 허용
resizabletrue모든 컬럼 너비 조절 허용
enableCellTextSelectiontrue셀 텍스트 드래그 선택 허용
paginationtrue페이지네이션 활성화
paginationPageSize20페이지당 기본 행 수
paginationPageSizeSelector[10, 20, 50, 100, 300, 500]페이지 크기 선택 옵션
자주 쓰는 커스텀 옵션 예시
const myGridApi = GridCommon.init(document.querySelector('#myGrid'), {
  columnDefs: columnDefs,
  rowData: rowData,

  // 행 선택 (단일: singleRow / 다중: multiRow)
  rowSelection: { mode: 'multiRow' },

  // 행 높이 커스텀
  rowHeight: 46,
  headerHeight: 46,

  // 페이지네이션 끄기
  pagination: false,

  // 드래그 순서 변경
  rowDragManaged: true,
  animateRows: true,
});
3. GridToolbar — 툴바 기능
그리드 API 인스턴스를 첫 번째 인자로 전달합니다.
패널이 열리는 버튼(resetPinned, columnSelect)은 this를 두 번째 인자로 넘겨 버튼 기준 위치에 패널을 표시합니다.
툴바 HTML 패턴
<div class="grid-toolbar w-full flex items-center text-sm my-4">
  <h3 class="text-lg">리스트 제목 - 총 N개의 결과</h3>
  <div class="ml-auto flex gap-1">
    <button onclick="GridToolbar.resetAlign(myGridApi)"
      class="bg-slate-100 hover:bg-slate-200 px-3 py-1.5 rounded text-xs cursor-pointer">정렬 초기화</button>
    <button onclick="GridToolbar.resetFilter(myGridApi)"
      class="bg-slate-100 hover:bg-slate-200 px-3 py-1.5 rounded text-xs cursor-pointer">필터 초기화</button>
    <button onclick="GridToolbar.resetPinned(myGridApi, this)"
      class="bg-slate-100 hover:bg-slate-200 px-3 py-1.5 rounded text-xs cursor-pointer">컬럼 고정 선택</button>
    <button onclick="GridToolbar.columnSelect(myGridApi, this)"
      class="bg-slate-100 hover:bg-slate-200 px-3 py-1.5 rounded text-xs cursor-pointer">컬럼 표시 선택</button>
    <button onclick="GridToolbar.csvDown(myGridApi)"
      class="bg-green-100 hover:bg-green-200 px-3 py-1.5 rounded text-xs cursor-pointer">CSV 다운로드</button>
  </div>
</div>
함수 목록
함수인자설명
GridToolbar.resetAlign(gridApi) gridApi 모든 컬럼 정렬 상태를 초기화합니다.
GridToolbar.resetFilter(gridApi) gridApi 모든 컬럼 필터를 초기화합니다.
GridToolbar.resetPinned(gridApi, triggerEl) gridApi, this 컬럼별 좌측 고정 여부를 체크박스로 선택하는 패널을 엽니다. 하단에 전체 초기화 버튼 포함. dragColumn은 목록에서 제외됩니다.
GridToolbar.columnSelect(gridApi, triggerEl) gridApi, this 컬럼별 표시/숨김을 체크박스로 선택하는 패널을 엽니다. 하단에 전체 선택 / 선택 해제 버튼 포함. dragColumn은 목록에서 제외됩니다.
GridToolbar.csvDown(gridApi) gridApi 현재 그리드 데이터를 CSV로 다운로드합니다. 포매터가 적용된 값이 그대로 출력됩니다.
GridToolbar.editRow(gridApi, triggerEl) gridApi, this 드래그 순서 변경 모드를 활성화합니다. colId: 'dragColumn' 컬럼이 정의되어 있어야 합니다. 변경/취소 버튼(id="btnSaveOrder", id="btnCancelOrder")과 함께 사용합니다.
editRow 사용 시 HTML 패턴
<!-- 순서 변경 전용 버튼 그룹 -->
<div class="flex items-center gap-2">
  <button onclick="GridToolbar.editRow(myGridApi3, this)"
    class="bg-gray-800 hover:bg-gray-700 text-white px-3 py-1.5 rounded text-xs cursor-pointer">전시 순서 변경</button>
  <button id="btnSaveOrder"
    class="hidden bg-emerald-600 hover:bg-emerald-500 text-white px-3 py-1.5 rounded text-xs cursor-pointer">변경</button>
  <button id="btnCancelOrder"
    class="hidden bg-white border border-gray-300 hover:bg-gray-50 text-gray-700 px-3 py-1.5 rounded text-xs cursor-pointer">취소</button>
</div>

<!-- columnDefs에 dragColumn 정의 필수 -->
// columnDefs 예시
{
  colId: 'dragColumn',     // GridToolbar.editRow가 이 colId를 찾아 제어함
  rowDrag: true,
  width: 50, minWidth: 50, maxWidth: 50,
  pinned: 'left',
  sortable: false, filter: false, resizable: false,
  suppressHeaderMenuButton: true,
  hide: true               // 초기에는 숨김 상태로 정의
}
4. GridFormatters — 셀 값 포매터
컬럼 정의의 valueFormatter 속성에 지정합니다. 화면 표시 값만 변환하며 실제 데이터는 유지됩니다.
포매터입력 예출력 예설명
GridFormatters.currencyFormatter 102000 102,000원 3자리 콤마 + '원'. null/빈값은 - 출력
GridFormatters.rateFormatter 0.15 또는 15 15% 소수(0~1) 또는 정수(1 이상) 모두 자동 인식. null은 -
GridFormatters.dateTimeFormatter 2026-06-22T11:15:30 2026-06-22 11:15:30 ISO 문자열 → yyyy-mm-dd HH:MM:SS. null은 -
GridFormatters.dateFormatter 2026-06-22T11:15:30 2026-06-22 날짜만 표시. null은 -
사용 예시
const columnDefs = [
  {
    field: 'salePrice',
    headerName: '판매가',
    valueFormatter: GridFormatters.currencyFormatter
  },
  {
    field: 'discountRate',
    headerName: '할인율',
    valueFormatter: GridFormatters.rateFormatter
  },
  {
    field: 'createdAt',
    headerName: '등록 일시',
    valueFormatter: GridFormatters.dateTimeFormatter
  },
];
5. GridUtils — 셀 렌더러
컬럼 정의의 cellRenderer + cellRendererParams로 사용합니다.
actionButtonsCellRenderer — 버튼 셀
{
  colId: 'actions',
  headerName: '관리',
  width: 240,
  sortable: false, filter: false, resizable: false,
  cellRenderer: GridUtils.actionButtonsCellRenderer,
  cellRendererParams: {
    buttons: [
      {
        label: '수정',
        variant: 'primary',      // primary | secondary | danger | default(생략가능)
        onClick: (data) => {
          location.href = '/admin/edit?id=' + data.id;
        }
      },
      {
        label: '삭제',
        variant: 'danger',
        onClick: (data) => {
          if (confirm('삭제하시겠습니까?')) { /* 삭제 처리 */ }
        }
      },
      {
        label: '미리보기',
        show: (data) => data.displayStatus === '전시', // 조건부 노출 (선택)
        onClick: (data) => { window.open(data.link); }
      },
    ]
  }
}
variant색상용도
primary검정주요 액션 (수정, 저장)
secondary파랑보조 액션 (조회, 미리보기)
danger빨강삭제·취소 등 비가역 액션
default (생략)흰색 테두리일반 액션
imageCellRenderer — 이미지 셀
{
  field: 'prodThumb',
  headerName: '이미지',
  width: 80,
  cellRenderer: GridUtils.imageCellRenderer,
  cellRendererParams: {
    style: 'square',   // 'circle' | 'square'  (기본값: 'circle')
    w: 50,             // 가로 px  (기본값: 40)
    h: 40              // 세로 px  (기본값: 40)
  }
}
linkCellRenderer — 링크 셀
{
  field: 'productName',
  headerName: '상품명',
  cellRenderer: GridUtils.linkCellRenderer,
  cellRendererParams: {
    getUrl: (data) => data.link || '#',   // URL 생성 함수
    target: '_blank',                      // 링크 target (기본값: '_blank')

    // onClick을 정의하면 href 이동 대신 콜백 실행
    onClick: (data) => { console.log(data); }
  }
}
